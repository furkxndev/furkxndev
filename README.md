## Hakkımda

Uçtan uca ürün geliştiriyorum — arayüz, API ve veritabanı şeması dahil. QR ile masadan sipariş alıp kartla ödeme tahsil eden bir restoran sistemi, yapay zekâ destekli bir seyahat rota platformu ve sahiplendirme odaklı bir mobil uygulama bunların başlıcaları.

Bir işi "çalışıyor" noktasında bırakmıyorum: kimlik doğrulama, Socket.IO ile gerçek zamanlı senkron, ödeme entegrasyonu, migration tabanlı şema yönetimi ve Docker ile dağıtım da işin parçası. Yapay zekâyı süs olarak değil ürünün merkezinde kullanıyorum. Yan tarafta Unity ile fizik tabanlı 2D oyunlar yazıyor, tekrar eden işleri Playwright + GitHub Actions ile otomatikleştiriyorum.

**Şu anki odağım:** dağıtık servis mimarisi, gerçek zamanlı sistemler ve LLM destekli ürün akışları.
